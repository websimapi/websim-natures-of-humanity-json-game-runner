AI Modder

Give the AI instructions to modify or expand the game.json. The engine will replace its in-memory game with the AI's JSON response. Tip: Ask for specific changes like "Add a late-life travel arc with art-focused dilemmas" or "Introduce a Random Catastrophe system keyed to environment."

This uses the provided websim.chat API. The AI must return valid JSON only that conforms to the schema in the current game.json's 'schema' field.
